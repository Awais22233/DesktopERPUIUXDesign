# Backup guide for the customer (Roman Urdu)

## Roz ka kaam
1. Din ke aakhir me **USB drive ya SSD laga dein**.
2. Program band karein (band karte waqt aakhri backup banta hai aur drive par copy hota hai).
3. Drive nikal kar mehfooz rakhein. Phir laptop band karein.

Agar drive laga hua nahi hoga to program band karte waqt poochega: **Retry** (drive laga kar), **Close without the extra copy**, ya **Stay in the program**.

## Pehli dafa setup (aap ya hum)
1. Program me **Backup & restore** kholein.
2. **Copy 1** ke samne **Choose folder** dabayein aur USB drive ka folder chunein (jaise `E:\ERP-Backup`). **Test** dabayein: "Working" aana chahiye.
3. Google Drive chahiye to Google ka "Drive for Desktop" install karein (**Mirror files** chunein), Drive me `ERP-Backup` folder banayein aur usay **Copy 2** me chunein.
4. **Backup now** dabayein aur dekhein ke drive me file aayi.

## Kitni purani copies rehti hain
Drive par khud ba khud: aakhri 14 din, 8 hafte aur 12 mahine. Baqi purani hat jati hain, is liye drive bharta nahi.

## Warning
Agar 3 din se koi bahari copy nahi gayi to Dashboard par pila banner aayega. Drive lagayein aur **Backup now** dabayein.

## Mahine me ek dafa
**Backup & restore** → **Check my backups now**. Sab "Opens correctly" aur sales/customers barabar hone chahiye.

## Naya laptop ho ya program dobara install karna ho
1. Naye laptop par program install karein.
2. Hamein naye laptop ka **Computer ID** bhejein. Hum nayi license key dein (key har laptop ke liye alag hoti hai).
3. Key paste karein. Phir pehli screen par **I already have data: restore from a backup** dabayein.
4. USB lagayein ya Google Drive wala folder chunein, sab se naya backup chunein, **Restore this backup** dabayein.
5. Program dobara khulega. Purana username aur password wahi chalega. Sab hisaab, stock aur photos wapas aa jati hain.
