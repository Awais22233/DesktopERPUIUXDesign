Install in four steps

  1. Download and run the installerOpen the downloaded file. It installs for your Windows user and adds a desktop shortcut. No internet is needed after the download.
  2. If Windows shows “Windows protected your PC”Click More info, then Run anyway. This message appears for new software from a small publisher; the file is the one published here (see “Verify your download” below).
  3. Open Wholesale ERP and copy the Computer IDThe first screen shows a Computer ID. Press Copy and send it to your software provider.
  4. Paste the license key you receiveYour provider sends back a license key made for this computer only. Paste it into the same screen and press Activate, then create your shop’s admin account.

Good to know

  • The license works on this one computer. If you change computers, ask your provider for a new key.
  • All your data stays on your computer. Use Backup & Restore in the menu to keep copies on a USB drive.
  • Uninstalling does not delete your data.
